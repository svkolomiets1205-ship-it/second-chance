Другий шанс

## Як запустити сайт

1. Відкрий папку `second-chance`.
2. Відкрий у ній термінал PowerShell.
3. Введи:

```powershell
.\start.cmd
```


## Якщо запускаєм на іншому комп’ютері або після розпакування ZIP

1. Встанови Node.js LTS із https://nodejs.org/ (разом із npm).
2. Закрий і знову відкрий термінал у папці `second-chance`.
3. Один раз встанови потрібні пакети:

```powershell
npm.cmd install
```

4. Запусти сайт:

```powershell
.\start.cmd
```
